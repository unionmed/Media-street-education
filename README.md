# Media Street — Learning & Programme Promotion

Static bilingual (English/Arabic) website for Media Street's initial professional-learning affiliate direction.

## Included pages

- `index.html` / `arabic.html` — home page and team introduction.
- `courses.html` / `arabic-courses.html` — three initial programme selections with direct provider links.
- `guides.html` / `arabic-guides.html` — three original editorial guides.
- `legal.html` / `arabic-legal.html` — affiliate disclosure, editorial position and privacy information.

The current programme links are direct, non-affiliate provider links. Replace them only after an affiliate/referral agreement is approved and add the partner disclosure beside each changed link.

## Publishing

Upload the contents of this folder (not the ZIP itself) to the root of `unionmed/Media-street-education`.

For free GitHub Pages, the repository must be public. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**. The public site URL will then appear on that same Pages screen.
